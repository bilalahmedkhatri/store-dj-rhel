  🛠️ PHASE 1: The "Safety & Data Foundation" (Immediate)
  Goal: Fix critical security flaws and prepare the database for professional display.

   1. Security Patch (Webhook): Implement HMAC-SHA256 signature verification in app/views/webhooks.py. We cannot manage   
      data that can be spoofed.
   2. Private Media Layer: Configure MerchantProfile document fields (cnic, utility_bill) to use a private storage backend
      so they aren't publicly accessible via URL guessing.
   3. Model Decorators: Add @property methods to Product and Collection models to return "Primary Name" and "Primary      
      Image" across languages. This prevents the admin from breaking when translations are missing.

  ---

  🎨 PHASE 2: UI-UX Overhaul (Solving the "Coozy" Problem)
  Goal: Make data visible, breathable, and professional using the unfold theme features.

   1. The "Clean Row" Strategy:
       * Truncation: Limit character counts in list_display for descriptions.
       * Status Badges: Use Unfold’s display decorators to turn text status (e.g., "PAID") into colored badges (Green for 
         Paid, Red for Cancelled).
       * Currency Formatting: Create a helper to format all prices in PKR with commas (e.g., ₨ 2,500).
   2. Advanced Filtering: Implement unfold.contrib.filters (Dropdown filters) to replace the default sidebar filters that 
      take up too much horizontal space.
   3. Search Optimization: Enable search_fields across relationships (e.g., searching an Order by Customer Email or       
      Product SKU).

  ⚙️ PHASE 3: Functional Logic & Workflows
  Goal: Move from "Static Data Entry" to "Business Process Automation".

   2. Product Variant Matrix:
       * Refactor the ProductVariantInline to use TabularInline for space-saving.

   3. Order Fulfillment Logic:
       * Implement a transition validation. An order cannot move to "Shipped" unless a "Tracking Code" is entered in the  
         fulfillment section.

  🚀 PHASE 4: Background Tasks & Enterprise Scaling
  Goal: Handle heavy data processing without slowing down the Admin UI.
